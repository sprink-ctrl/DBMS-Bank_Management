## 🛡️ Admin Features

### 1. Admin Authentication

* Admin login/logout

### 2. Admin Dashboard

* Total customers
* Total accounts
* Active accounts
* Frozen accounts
* Total transactions
* Failed transactions


### 3. Customer & Account Management

* Search customer
* View customer profile
* Edit customer details
* View customer's accounts
* Freeze/unfreeze account
* Close account

### 4. Transaction Monitoring

* View transactions
* Search by transaction ID/customer/account
* Filter by date/type/status
* View transaction details
* Sort by amount/date

### 5. Transaction Flagging

* Flag high-value transactions


### 6. Account Security

* Activate/deactivate accounts
* Reset customer credentials
* View failed login attempts

(OPTIONAL)  7. Audit Log

* Record admin actions
* Record who performed the action
* Record affected customer/account
* Record timestamp
* Search/filter logs
